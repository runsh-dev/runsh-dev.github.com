# Life & BLOG

你好，欢迎来到我的博客。我是一名前端开发者，工作在上海，周末生活在无锡。这里放着这些年写下的技术笔记、生活日记，以及一些读书和成长中的想法。

最初写博客时，记录得更多的是工作和学习中遇到的问题：JavaScript 的原型与 this 指向、React 的使用、Git 命令，还有开发工具的折腾过程。把零散的经验整理成文章，方便自己回头查阅，也给遇到同样问题的人一点参考。

后来，关于生活的记录渐渐多了起来。上海和无锡之间的往返、节假日的见闻、学车的经历、读过的书，都成了文章里的内容。成为丈夫和父亲之后，日记里也多了家人的身影：有陪小宝玩耍、和老婆一起出门的日常，也有对教育、陪伴与责任的思考。

很多时候，一篇文章写的就是普通的一天。下雨没去成的商场，傍晚去外滩拍到的亮灯，下班后一起回家的路，都可以记上一笔。把这些小事写下来，日后翻看时，就有了回想当时生活的线索。

这里也收着对故乡的回忆、读书时的感想和年度总结。不同阶段关心的事情会变，文章便跟着生活慢慢往前走。有问题时写写解决的经过，有感触时多聊几句，平常的日子就照常记录。

你可以从[文章归档](https://runsh.dev/articles)开始，按年份翻翻旧文，也可以到[关于我](https://runsh.dev/about)了解更多。谢谢你来读这些记录。
