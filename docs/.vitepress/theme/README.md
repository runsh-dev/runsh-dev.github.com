# 余白 · 阅读主题

以中文长文为主，同时照顾中英文混排与技术文章。暖纸色、墨绿色、少量赭色用于建立层次；装饰集中在首页，文章正文保持安静。

## 排版参数

| 项目              | 默认值                                          |
| ----------------- | ----------------------------------------------- |
| 桌面正文宽度      | `45rem`，默认浏览器字号下为 720px，约 34 个汉字 |
| 桌面字号 / 行高   | `1.3125rem` / `1.667`，即 21px / 35.007px       |
| 手机字号 / 行高   | `1rem` / `1.667`，即 16px / 26.672px            |
| 段后间距          | `1.5rem`，默认 24px                             |
| 正文字距          | `normal`                                        |
| 桌面字号切换      | 小 18px、标准 21px、大 24px（使用 rem）         |
| 手机字号切换      | 小 15px、标准 16px、大 18px（使用 rem）         |
| 字体切换          | 思源宋体 / 系统黑体栈                           |
| 代码块字号 / 行高 | `0.875rem` / `1.75`，即 14px / 24.5px           |

字号、行高、段后间距和字距参照 [Adobe 思源宋体简体中文页面](https://source.typekit.com/source-han-serif/cn/) 的介绍正文，而非页面中的 24px 字重展示区。参考页在 1280px 视口实测为 21px / 35.007px，在 390px 视口实测为 16px / 26.672px；博客在 768px 以下切换至手机字号。标题沿用博客已有层级。

阅读设置保存在当前浏览器的 `yohaku-reading-preferences` 中，仅作用于文章正文。浏览器禁用存储或旧数据损坏时，页面仍能使用默认设置和即时切换。

## 维护入口

- `styles/vars.scss`：共享色彩、字体栈、正文宽度和字号令牌。
- `styles/yohaku.scss`：正文、标题、列表、引用、表格、键盘焦点、减少动态效果。
- `components/ReadingControls.vue`：阅读选项与本地偏好。
- `components/VPDoc.vue`：阅读选项与文章容器的连接。
- `components/VPHome.vue`、`PostCard.vue`：首页与文章列表。

中文正文和标题优先使用思源宋体（Source Han Serif SC）。`styles/myfonts.scss` 分别映射仓库现有的 Regular / Medium / SemiBold / Bold 字体文件至 400 / 500 / 600 / 700 字重，优先使用设备已安装的对应字体，否则由本站提供 OTF 文件。字体使用 `font-display: swap`，加载期间显示后备字体。拉丁界面字体使用本地 SN Pro 可变字体，不依赖第三方字体服务。

修改后运行 `npm run docs:build`。浏览器重点检查首页、`/articles`、年份索引和包含长标题 / 列表 / 表格 / 代码的文章；覆盖浅深主题、320px / 390px / 768px / 桌面宽度。注意 VitePress 对段落和代码有直接字号、行高规则，不能仅依赖父容器继承值。

`skills/design-system/` 保留较早版本的设计参考资产；当前运行中的博客主题以本目录的令牌与实现为准。
