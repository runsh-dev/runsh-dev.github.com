# Life & BLOG · 阅读主题

以 apple-design 为基础的个人博客：白色画布、浅灰内容分区、中文思源宋体与西文系统字体、黑色文字，配合半透明导航和轻微的按压反馈。深色模式使用中性灰黑，不改变信息层级。

## 页面结构

- 首页：参考 blog.polebug.com，单个面板内两栏展示最近 5 篇文章（日期、带荧光笔标记的标题、开头摘要、继续阅读），底部链接到全部文章。摘要优先取 `<!-- more -->` 之前的内容，否则取开头几段。
- 归档：按年份分组的文章列表；年份索引保持原有路由。
- 阅读页：返回入口、文章信息、正文和上下篇导航。
- 页脚：品牌、归档、关于和 GitHub 链接；版权配置沿用站点设置。

## 排版

| 项目       | 默认值                                                              |
| ---------- | ------------------------------------------------------------------- |
| 中文字体   | 思源宋体（Noto Serif SC），按 Unicode 范围从 CDN 加载               |
| 西文字体   | Lato（Google Fonts，400/700），英文与数字优先使用                    |
| 文字颜色   | 浅色模式正文和标题 #000，辅助文字和链接悬停 #666                     |
| 正文宽度   | 宽屏 1041px，居中；桌面窄屏两侧 120px，平板两侧 40px，手机两侧 20px |
| 正文字号   | 各屏幕统一 16px（1rem）                                              |
| 正文行高   | 1.85（约 29.6px）                                                    |
| 正文字重   | Regular（400）                                                      |
| 字符间距   | 自然字距                                                             |
| 段落间距   | 1.35em                                                               |
| 文章标题   | Regular（400）；26px，手机 22px；行高 1.6                            |
| 正文标题   | h1 21px、h2 20px、h3 18px、h4 16px；700；行高 1.45                   |

页面统一使用中西文混排字体和各屏幕尺寸下的标准字号，不提供字号或字体切换，也不再读取或保存阅读偏好。浏览器中已有的旧偏好不会影响页面排版。字体按 Unicode 范围匹配，中文标点保留思源宋体比例间距，西文标点使用系统字体；代码中的中文也使用思源宋体，西文保持默认等宽字体。

字体、文字颜色、字距、行高、段间距与阅读栏宽度参考 [思源宋体展示页](https://source.typekit.com/source-han-serif/cn/) 中截图对应的正文区域。1024px 及以上使用 21px 标准正文，769–1023px 使用 18px，768px 及以下使用 16px。1301px 及以上的阅读栏最大 1041px；1024–1300px 两侧留白 120px，641–1023px 两侧 40px，640px 及以下两侧 20px。代码保持默认 OpenType 间距。

## 交互与无障碍

按压时即时反馈；悬停效果仅在支持 hover 的设备启用。没有自动播放或入场动画。减少动态效果时关闭位移、缩放和顺滑滚动；减少透明度时导航使用实色；高对比度时加深文字与边界。所有内容链接可用键盘访问。

## 维护入口

- styles/vars.scss：共享色彩、字体和阅读尺寸。
- styles/yohaku.scss：正文排版、焦点与无障碍样式。
- styles/layouts/nav.scss：半透明导航与移动布局。
- components/VPHome.vue、HomePostsPreview.vue：首页；摘要提取在 posts.data.ts。
- components/VPDoc.vue：阅读页布局。
- components/JournalFooter.vue：通用页脚。
- docs/public/journal-city.jpg：由已有 docs/publish/img.png 转换的压缩照片，原图保留。
