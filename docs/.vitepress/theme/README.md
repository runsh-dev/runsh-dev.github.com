# Life & BLOG · 阅读主题

以 apple-design 为基础的个人博客：白色画布、浅灰内容分区、思源宋体、克制的蓝色链接，配合半透明导航和轻微的按压反馈。深色模式使用中性灰黑，不改变信息层级。

## 页面结构

- 首页：居中介绍、最新文章与城市照片、六篇近期文章、站点题记。
- 归档：按年份分组的文章列表；年份索引保持原有路由。
- 阅读页：返回入口、文章信息、正文和上下篇导航。
- 页脚：品牌、归档、关于和 GitHub 链接；版权配置沿用站点设置。

## 排版

| 项目       | 默认值                                                              |
| ---------- | ------------------------------------------------------------------- |
| 界面与正文 | 思源宋体，优先已安装字体，再加载随站字体                            |
| 正文宽度   | 宽屏 1041px，居中；桌面窄屏两侧 120px，平板两侧 40px，手机两侧 20px |
| 桌面字号   | 标准 21px，使用 rem                                                 |
| 平板字号   | 标准 18px，使用 rem                                                 |
| 手机字号   | 标准 16px，使用 rem                                                 |
| 正文行高   | 1.667；标准桌面约 35px，平板约 30px，手机约 26.7px                  |
| 正文字重   | Regular（400）                                                      |
| 字符间距   | 自然字距，开启 OpenType `palt` 比例间距                             |
| 段落间距   | 24px，使用 rem                                                      |
| 文章标题   | Heavy（900）；桌面 48px、平板 36px、手机 28px；行高 1.44            |
| 二级标题   | 桌面 30px、平板 22px、手机 20px；行高 1.44                          |

页面统一使用思源宋体和各屏幕尺寸下的标准字号，不提供字号或字体切换，也不再读取或保存阅读偏好。浏览器中已有的旧偏好不会影响页面排版。

字体、字距、行高、段间距与阅读栏宽度参考 [思源宋体展示页](https://source.typekit.com/source-han-serif/cn/) 中截图对应的正文区域。1024px 及以上使用 21px 标准正文，769–1023px 使用 18px，768px 及以下使用 16px。1301px 及以上的阅读栏最大 1041px；1024–1300px 两侧留白 120px，641–1023px 两侧 40px，640px 及以下两侧 20px。代码保持默认 OpenType 间距。

## 交互与无障碍

按压时即时反馈；悬停效果仅在支持 hover 的设备启用。没有自动播放或入场动画。减少动态效果时关闭位移、缩放和顺滑滚动；减少透明度时导航使用实色；高对比度时加深文字与边界。所有内容链接可用键盘访问。

## 维护入口

- styles/vars.scss：共享色彩、字体和阅读尺寸。
- styles/yohaku.scss：正文排版、焦点与无障碍样式。
- styles/layouts/nav.scss：半透明导航与移动布局。
- components/VPHome.vue、HomePostsPreview.vue、PostCard.vue：首页。
- components/VPDoc.vue：阅读页布局。
- components/JournalFooter.vue：通用页脚。
- docs/public/journal-city.jpg：由已有 docs/publish/img.png 转换的压缩照片，原图保留。

验证命令为 npm run docs:build。检查首页、文章归档、年份索引、关于页和长文章，覆盖浅深主题、320px / 390px / 768px / 桌面宽度及旧偏好不再生效的情况。skills/design-system/ 是早期设计参考，当前页面以此目录为准。
